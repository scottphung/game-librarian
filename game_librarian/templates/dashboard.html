  1. Refresh the data: python -m game_librarian sync, then python -m game_librarian export-report.

What the report shows

  • Player Reception: games with review data, total reviews, the review-weighted positive rate and the simple average of game percentages, compared by review volume, production label and tag, plus the same four-year ranking as this website.
  • Awards Explorer: verified winners and nominees of The Game Awards by year, category and game, showing which entries match a catalog game (including awards that went to an original release of the edition Steam sells), which are on Steam but outside the catalog, and which have no Steam app.
  • About the data: definitions, the ranking rules, the ranking window of the loaded export and the limits of the curated coverage.

The report uses only data this project collects. It has no price, player-count or historical trend data: the catalog stores only the latest values from each sync.
