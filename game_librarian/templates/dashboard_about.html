What this dashboard is

Trending games charts the games of the Trending page from the snapshots this site saves; it is on the website only, not in the Power BI report. Player reception, Awards and this page are an HTML version of the Power BI report in reporting/, with the same measure definitions, calculated from the catalog on every page load. They cover the {{ dash.games|number }} catalog games ({{ (dash.games - dash.promoted)|number }} hand-picked, {{ dash.promoted|number }} promoted from reviewed candidates), not all of Steam.

Player reception

Review counts are Steam's review summaries: Steam purchasers, all languages. The review-weighted positive rate pools every review, so games with many reviews dominate. The average game positive rate gives every game the same weight. A game counts once, however many tags or awards it has.

Five-year ranking

Only games released {{ dash.window.start|day }} – {{ dash.window.end|day }} are ranked. A game’s highest-priority verified award result sets its group: {{ dash.rank_groups|join("; ") }}. Within a group, more distinct verified wins rank higher, then more distinct verified nominations; Steam reception breaks the remaining ties (games with at least {{ dash.reliable_reviews|number }} reviews first, highest positive share first, then more reviews), then the title and the Steam app ID. Production labels play no part. A game with an award keeps its place without usable review data; a game with neither an award nor usable reviews is Unranked. Ranks come from the whole catalog, so filters never renumber them.

This is Game Librarian’s editorial discovery ranking, not an objective measure of quality. Award coverage is incomplete, so “No award recorded” does not mean a game never received an award.

The website ranks the five full years before {{ dash.window.end.year }} plus {{ dash.window.end.year }} so far. The Power BI report keeps its own window, the four years up to the export day, so its ranks can differ.

Refreshing

Run python -m game_librarian sync, then reload the page. Nothing refreshes automatically unless you schedule the sync. The optional Power BI version needs export-report and Power BI Desktop (see reporting/README.md).

Snapshots, trends and what is not included

Since version 0.5 each sync also saves dated snapshots of player counts and review totals, and the latest price per game. They appear on the Trending games page and are not part of the Power BI export. A snapshot is one moment; a change over time needs snapshots that were actually saved on different days, and nothing before the first snapshot can be reconstructed. Sales, revenue and Steam's Top Sellers chart are not collected: review and player counts are not sales.
