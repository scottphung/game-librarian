What this dashboard is

An HTML version of the Power BI report in reporting/, with the same measure definitions. It is calculated from the catalog on every page load, so no export is needed. It covers the {{ dash.games|number }} catalog games ({{ (dash.games - dash.promoted)|number }} hand-picked, {{ dash.promoted|number }} promoted from reviewed candidates), not all of Steam.

Player reception

Review counts are Steam's review summaries: Steam purchasers, all languages. The review-weighted positive rate pools every review, so games with many reviews dominate. The average game positive rate gives every game the same weight. A game counts once, however many tags or awards it has.

Four-year ranking

Only games released {{ dash.window.start|day }} – {{ dash.window.end|day }} are ranked. Verified AAA games come first, then AA, then Indie and Unclassified together; within a tier, more positive Steam reviews rank higher. Ranks come from the whole catalog, so filters never renumber them. This is a discovery order, not a judgment of quality.

Refreshing

Run python -m game_librarian sync, then reload the page. Nothing refreshes automatically unless you schedule the sync. The optional Power BI version needs export-report and Power BI Desktop (see reporting/README.md).

Not included

Prices, player counts and trends over time: the project stores only the latest values, so there is no history to chart.
