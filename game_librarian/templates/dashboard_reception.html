Two ways to measure reception

Review-weighted positive rate: all positive reviews ÷ all reviews of the selected games, so games with many reviews dominate.

Average game positive rate: the mean of each game's own positive share, so every game counts once.

Reviews are Steam's review summaries: Steam purchasers, all languages. A game counts once, however many tags or awards it has. Definitions: About the data.
