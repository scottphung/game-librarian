How the ranking works

Which games. Only games released in the last four years: from {{ window.start|day }} to today, {{ window.end|day }}. The window moves forward every day. Older games, games not released yet and games without an exact release date on Steam are not ranked; you find them under All games.

Order. Verified AAA games come first, then verified AA games, then Indie and Unclassified games together. Within each tier, the game with more positive Steam reviews ranks higher. So an AAA game can rank above an AA game, and an AA game above an Indie or Unclassified game, even when it has fewer positive reviews.

Ties (same tier, same number of positive reviews) go to the title A–Z, then the Steam app ID. Unranked games were released in the window but have no usable positive review count (not fetched yet, no reviews, or inconsistent counts). They are listed after the ranked games.

What a rank means. It is a discovery order, not a judgment of quality. Counting positive reviews favors popular games, and games released earlier in the window, because they have had more time to collect reviews.

Production labels and awards come from this project’s hand-curated data: most games have no verified label (Unclassified), and the awards cover two categories of The Game Awards. Awards are not part of the rank. Searching and filtering never change a game’s rank.
