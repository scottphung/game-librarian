How the ranking works

Which games. Only games released from {{ window.start|day }} to today, {{ window.end|day }}: the five full years before {{ window.end.year }}, plus {{ window.end.year }} so far. The window moves forward every 1 January. Older games, games not released yet and games without an exact release date on Steam are not ranked; you find them under All games.

1. Award group. A game’s highest-priority verified award result puts it in one of these groups. Every game in a group ranks above every game in a later group, whatever its reviews:

    {% for group in rank_groups %}
  1. {{ group.name }}{% if not group.recorded %} (no verified results recorded yet){% endif %}
    2. {% endfor %}

2. Number of awards. Within a group, more distinct verified wins rank higher; with equal wins, more distinct verified nominations. A nomination never counts as a win, and a result recorded twice counts once. Under the rank number, each card names its group and counts; its first listed award is the one that sets the group.

3. Steam reception breaks the remaining ties, as in Best player reception: games with at least {{ reliable_reviews|number }} Steam reviews first, highest positive share first, then more reviews; then games with fewer reviews, in the same order; then games without a usable review summary. Last come the title A–Z and the Steam app ID, so every rank is distinct.

Missing data. Missing, zero or inconsistent review counts are never read as zero reviews or 0% positive. A game with a verified award keeps its award-based place without them, and its card says the review data is unavailable. A game with no award recorded and no usable review summary is Unranked: it has no number and is listed after the ranked games.

What a rank means. This is Game Librarian’s editorial discovery ranking, not an objective measure of game quality. Award coverage is incomplete: the curated data covers selected organizations, categories and years, so “No award recorded” does not mean a game has never received an award. An award to the original release of a remaster or edition counts for the edition Steam sells and is marked “for the original release”.

Production labels (AAA, AA, Indie) do not affect the rank; use the Production label filter to see them. Searching and filtering never change a game’s rank, and neither do the other sort orders or the collections: a number is always the game’s place among all catalog games in the window.

Other sort orders. Most positive Steam reviews counts positive reviews. Best player reception lists games with at least {{ reliable_reviews|number }} Steam reviews first, highest positive share first, so a handful of reviews cannot lead; games with fewer reviews follow. Most players on Steam uses each game's newest player-count snapshot, taken by the sync: one moment, which varies with the time of day. Newest release uses exact Steam release dates up to today; unreleased games and games without an exact date follow A–Z. Games without review data come last in the review-based orders, and games without a player count come last in the player order.
